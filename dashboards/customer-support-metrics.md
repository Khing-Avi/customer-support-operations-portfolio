## Customer Support Performance Metrics Dashboard
## Objective

To track and monitor customer support performance metrics to improve service quality and operational efficiency.
| Metric | Description                 |
| ------ | --------------------------- |
| CSAT   | Customer Satisfaction Score |
| AHT    | Average Handling Time       |
| FCR    | First Contact Resolution    |
| QA     | Quality Assurance Score     |

| Ticket ID | Issue Type      | Resolution Time | CSAT | Agent Notes    |
| --------- | --------------- | --------------- | ---- | -------------- |
| 001       | Payment Issue   | 12 min          | 5    | Issue resolved |
| 002       | Account Login   | 8 min           | 5    | Password reset |
| 003       | Technical Error | 20 min          | 4    | Escalated      |

## Tools Used
Google Sheets
Microsoft Excel
CRM reporting tools

## Operational Benefit
Tracking these metrics helps support teams:
maintain service quality
identify process bottlenecks
improve response efficiency
